## About
Takes an ESP 8266 chip and adds a couple integrated circuits to read weather and luminosity.
Reports readings to a SQL Server database.
Adds a simple Python web server script to report daily readings.

## Improvements
Takes a Pico W cihp and adds various integrated circuites to read weather and luminosity.
A note about the ESP 8266 - I ran into issues with brownouts even while trying to add
counter measures like capacitors.  So version 2 set forth the Pico W.
